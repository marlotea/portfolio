## How posts work

Each post is a Markdown file in `src/posts/`. The file name becomes the URL slug, so this file lives at `#/writing/hello-world`.

Frontmatter at the top sets the title, date (`YYYY-MM-DD`) and a one-line summary:

```md
---
title: My post
date: 2026-12-01
summary: One sentence about it.
---
```

GitHub-flavored Markdown works, including lists, tables and [links](https://github.com/marlotea).
